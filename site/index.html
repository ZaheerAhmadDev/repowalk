Get started How it works

What is repowalk?

A repository opens as a folder. repowalk answers the four questions you always hit in an unfamiliar codebase: where to start, what a thing does, how it connects, and what matters. It reads the code with tree-sitter, resolves call and import edges, and renders the result as text, an interactive graph, an animated flow, and diagrams — all derived from the source on disk.

It is deliberately not a summarizer. AI writes code fast; repowalk is the verification layer you check the result against, using ground truth you can point at line by line.

One pass, two artifacts. A single learn() pass writes .repowalk/index.json (structure) and .repowalk/analysis.json (variables, control flow, types, modules). Both are versioned; a mismatch is a cache miss, never a silent misread.

Why it exists

Repositories grow faster than people can read them. Opening a large one usually means hitting four walls — each maps to a feature.

The wallHow repowalk breaks it
“Where do I even start?”Tour (reading order) and Map (orientation)
“What does this do, and why?”Explain cards and an editable, highlighted Text mode
“How does it connect?”Graph mode, an A→B flow trace, and dynamic Flow playback
“What parts matter?”Legend encoding (size = fan-in) and the Health report

Features

Five reading surfaces over one model of the code.

◆Map & Tour

Languages, LOC, entrypoints, module tree, largest files, hottest symbols — plus a computed reading order with a one-line “why” per item.

▤Text mode

File tree beside a syntax-highlighted pane with line numbers. Every selection stays in sync across panes.

⌂Explain cards

Docstring, full signature, file:line, callers, callees, and module role — everything clickable.

⇄Graph mode

Interactive call/import graph: pan, zoom, drag, real names, clustering and confidence filters. Low-confidence edges are drawn dashed.

▶Flow mode

An A→B trace with animated stage playback (playhead, step, 0.5×–2×) and a Feature tab that slices the call tree from an entrypoint.

▦Diagrams

Per-function control-flow graphs, a type/class structure diagram, and a module dependency diagram.

≡Usage & references

A per-file variable table (kind, type, reads/writes/uses, declaration) and all-use-sites for any symbol.

⌕Search

Fuzzy subsequence matching over symbols and paths, sortable by fan-in, LOC, or name; Ctrl+P quick open.

✎Notes

Bookmarks with free text stored in .repowalk/notes.json; a note whose target disappears is marked stale, never dropped.

◎Health & guardrails

Cycles (Tarjan), god-files by LOC percentile, complexity hotspots, and architecture rules from rules.json.

⤓Export

Mermaid, Graphviz DOT, hand-rolled SVG, a self-contained Markdown report, and PNG — shared by GUI and CLI, so outputs cannot drift.

⊙Repo 101

A thirty-second orientation card: what the repo is, how to build and run it, and where the entrypoints live.

How it works

Everything is derived at runtime from the source. There is no network code at all, and the same repo always gives the same result.

  1. repo
  2. walk (respects .gitignore)
  3. tree-sitter parse
  4. resolve edges
  5. analyze
  6. cache
  • Parsing: tree-sitter extracts definitions, doc comments, calls, and imports into a shared symbol/edge model.
  • Edge resolution: call sites become confidence tiers — exact, name-only, ambiguous, unresolved. The UI renders low-confidence edges as dashed and marked with a ?; a name-only hop is never shown as confirmed.
  • Analysis: variables (reads/writes/uses per file), per-function control-flow graphs, type/class structure, module boundaries, entrypoints and feature slices, cyclomatic complexity, and guardrail rules.
  • Tour: a topological sort of the import graph, ranked by fan-in, entrypoint status, docstring coverage, and depth.
  • Health: strongly connected components find cycles; LOC percentiles find god-files; rules.json produces addressable findings.
  • Incremental & deterministic: the cache is keyed per file (nanosecond mtime + size) and on the revision of the pipeline that produced it — a one-file edit re-analyzes one file, and an analyzer change can never silently serve stale output.

Install & run

You need a recent stable Rust toolchain.

  1. Clone and build: 
    git clone https://github.com/ZaheerAhmadDev/repowalk.git
cd repowalk
cargo build --release
  2. The binaries land at target/release/repowalk-gui and target/release/repowalk-cli.
  3. Install the CLI onto your PATH: 
    cargo install --path crates/cli
  4. Run it: 
    # GUI — opens the app on a repo (path optional)
./target/release/repowalk-gui /path/to/repo

# CLI — orientation in one screen
./target/release/repowalk-cli map /path/to/repo
Cache: opening a repo writes .repowalk/ next to it (gitignored). Delete it to force a cold learn.

CLI reference

A terminal twin of the GUI — the same core, the same numbers. Query commands accept --json for scripting.

CommandWhat it does
map <repo>Metrics, module tree, and health in one screen

explain <symbol> <repo>Signature, docs, callers, callees

GUI guide

The window is a sidebar plus four modes. One selection drives every pane.

  • Sidebar panels: Map, Tour, Search, Health, Notes, and Repo 101.
  • Mode buttons (or Tab): Text → Graph → Flow → Diagrams. Switching modes keeps your selection.
  • Export menu: architecture report, call graph / types / modules as Mermaid, DOT and SVG, plus PNG.
  • Explain cards carry Trace from here / Trace to here handoffs straight into Flow mode.

Known limits & non-goals

Deliberately not planned — these would make repowalk something it is not:

  • AI or LLM summaries (the point is ground truth you can verify yourself).
  • Refactoring or editing automation (repowalk tells you what the code is, not what it should be).
  • Git churn, diff, and watch modes (analysis is keyed to a checkout, not to history).
  • A Tauri or web port (a desktop app that never touches the network).

Known limits: an edge the analyzer cannot resolve is drawn dashed with a ?; a cross-file reference is listed as name-only rather than confirmed; a graph stops at 400 nodes and says what it hid instead of drawing a blank canvas.
