Open any codebase. Understand all of it.

v2 is the complete understanding suite: repowalk learns the repo once, then answers the whole set of questions in seven moves — learn → inventory → control flow → connections → structure → usage → export. Still pure static analysis: no AI, no network, no keys.

This page is honest about what runs today. Each group below carries a status line; nothing is advertised that you cannot point at in the code at this commit (ef11b9d, 2026-10-15).

The suite at a glance

  1. Learn — index the repo and cache the analysis (how-to).
  2. Inventory — LOC, languages, entrypoints, complexity, hotspots, god files, cycles.
  3. Control flow — a CFG per function: branches, loops, match arms, cyclomatic badge (how-to).
  4. Connections — the call/import graph with real names, clusters and filters (how-to).
  5. Structure — type diagrams (structs/enums/traits/classes) and the module DAG (how-to).
  6. Usage — per-file variables with read/write counts and highlight-all-uses (how-to), plus find-all-references (how-to).
  7. Export — Mermaid / DOT / SVG and a self-contained Markdown report (how-to).
