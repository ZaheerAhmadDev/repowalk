This page is a generic recipe; repowalk itself ships as a single HTML file and one stylesheet, with no JavaScript.

Tutorial

Add HTML, CSS & JS

Three files in your project folder are enough to publish a page.

Steps

  1. Create index.html, css/style.css, and js/app.js in your project folder.
  2. Link the stylesheet from <head>: 
    <link rel="stylesheet" href="css/style.css">
  3. Link the script just before </body>: 
    <script src="js/app.js"></script>
  4. Open index.html in a browser, or deploy it with GitHub Pages.

Minimal page

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Hello</h1>
  <script src="js/app.js"></script>
</body>
</html>

Tips

  • Keep the stylesheet in a css/ folder and scripts in a js/ folder; relative links then work wherever the site is hosted.
  • Prefer one stylesheet over inline styles — it caches once for every page.
  • When you ship to GitHub Pages, make sure index.html sits at the root of the published folder.
