Definition

Codebase understanding shouldn't require the cloud.

RepoWalk is an offline-first code intelligence tool that runs entirely on your device. It builds a precise symbol graph using tree-sitter, resolves dependencies without executing code, and surfaces architecture you can act on.

Unlike LLM-based explainers, RepoWalk never guesses. Every edge is classified as exact (fully resolved import) or name-only (heuristic), so you know what to trust. Reports, tours, and flow traces are deterministic and reproducible.

GUI-first, CLI-complete
Use the visual explorer for onboarding, or script repowalk in CI to generate architecture reports and block PRs that increase complexity.
Principles
  • Deterministic
    Same repo, same output. No temperature, no hallucinations.
  • Local-only
    File walk + tree-sitter parsing. No sockets, no telemetry.
  • Explainable edges
    Every dependency labeled with confidence and source range.
  • Tool-friendly
    JSON, DOT, Mermaid exports for docs and CI.

Four walls of modern codebase tools

RepoWalk is built to break the patterns that make onboarding slow, risky, and dependent.

AI Hallucinations
LLM explainers invent APIs and call chains. RepoWalk uses tree-sitter ASTs, so references are real ranges you can jump to.
Network & Privacy
Cloud tools require uploading code. RepoWalk never opens a socket. Your IP stays on disk, audit-able and offline.
Key Management
No API keys, no tokens, no rate limits. One binary, works in air-gapped environments, CI, or a locked-down laptop.
Context Limits
LLMs truncate at 32k tokens. RepoWalk maps 250k+ LOC by streaming file walks and incremental indexing without OOM.

How it works

1Walk— enumerate files, respect .gitignore
2Parse— tree-sitter per language, no exec
3Resolve— exact imports, then name-only
4Index— symbol table + edge store
5Visualize— GUI & reports
Language aware
Tree-sitter grammars for Rust, Python, TypeScript, JavaScript. Supports monorepos with mixed languages, with per-file parsing and error recovery.
Confidence explicit
Every edge stores kind: exact (import resolved to file), name-only (symbol name match), unresolved. UI shows color + tooltip so you know what to trust.
GUI + CLI parity
Same core in both. GUI is a thin viewer over the JSON graph. CLI can run in CI to emit reports, fail on complexity thresholds, or export Mermaid diagrams.

CLI Reference

Deterministic commands for mapping, querying, and exporting. Same output locally and in CI.

10 commands
Command Description Example
repowalk map Build full architecture map of target directory. Walks files respecting .gitignore, parses with tree-sitter, resolves imports to exact edges and falls back to name-only matches. map ./repo --format json
repowalk tour Generate guided walkthrough from entry points. Heuristics detect mains, routers, and handlers, then orders files by centrality for onboarding. tour --entry src/main.rs
repowalk explain Explain a symbol, file, or directory in local context. Shows enclosing scope, imports, callers, complexity, and why it exists without LLM. explain src/auth/middleware.ts:42
repowalk find Offline find definitions and references. Tree-sitter accurate ranges, works across languages, supports exact and name-only search modes. find --symbol verifyToken
repowalk flow Trace data and control flow between two symbols. Follows call graph and variable assignments across files to answer “how does X reach Y?”. flow --from login --to db.query
repowalk report Produce markdown/JSON report of architecture, complexity hotspots, coupling, and entry points. Ideal for CI artifacts and PR summaries. report --out arch.md
repowalk graph Export symbol graph in multiple formats. Supports DOT for Graphviz, JSON for tooling, and Mermaid for embedding in docs. graph --format mermaid
repowalk variables List variables, scopes, shadowings, and mutability. Highlights shadowed bindings and unused locals per file and per function. variables src/db/pool.py
repowalk complexity Calculate cyclomatic and cognitive complexity per function. Flags hotspots over threshold, useful as CI gate. complexity --threshold 15
repowalk refs Show incoming and outgoing references for a symbol. Includes file, line, confidence (exact vs name-only), and import path. refs --symbol UserService
JSON stable
All commands support --format json with stable schema for scripting.
Exit codes
0 = success, 1 = partial, 2 = error. Use in CI gates and pre-commit.
Offline proof
Run with --offline to assert no network. Fails if any socket is attempted.

Limits & honesty

What it is not
  • Not an LLM. Won't write code or invent explanations.
  • Not a type checker. Doesn't execute or type-check, only parses.
  • Not a security scanner. Finds structure, not vulnerabilities.
  • Best for static languages; dynamic Python/JS uses heuristics.
When to use something else
  • Need semantic search across docs → use vector search.
  • Need runtime profiling → use a profiler.
  • Monorepo over 1M LOC → index per package, not whole.
  • Heavy macro metaprogramming in Rust may lower exact rate.
