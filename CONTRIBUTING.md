# Contributing to repowalk

Contributions are welcome!

## Getting started
1. Fork and clone the repo.
2. Install Rust (stable). Run `cargo test` and `cargo clippy --workspace --all-targets --locked -- -D warnings` locally.
3. Make small, focused changes.

## Guidelines
- Follow existing code style; `cargo fmt` is expected.
- Add tests when fixing bugs or adding behavior.
- Keep commits focused and descriptive.
- For large changes, open an issue first.
