repowalk

Add HTML, CSS & JS

  1. Create `index.html`, `css/style.css`, `js/app.js` in your project folder.
  2. Link CSS: <link rel="stylesheet" href="css/style.css"> in <head>.
  3. Link JS: <script src="js/app.js"></script> before </body>.
  4. Open index.html in a browser, or use GitHub Pages to deploy.
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Hello</h1>
  <script src="js/app.js"></script>
</body>
</html>
